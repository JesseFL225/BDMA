step, everything the report should say, so you can write B2–B5 yourself.

## How the guide is organised

Each step (B2, B3, B4, B5) has the same parts:

- **Must mention**: needed to meet the rubric, with the exact numbers.
- **If there is room**: extra points that make the section stronger.
- **Avoid**: claims that are wrong or that a grader will penalise.
- **Use**: which figure or table goes with it.
- **Sources**: the file each number comes from.
